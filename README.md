# Editorial Carousel 中文滑动图文技能

`editorial-carousel` 是一个 Codex 技能，把中文文章、口播稿、教程和工作案例改编成可在手机上逐张阅读的图文。它适合用真实的对话、截图、对照结果和可复制的话术，讲清 AI 工具、科技实操及工作流程。默认采用卡通编辑风，也可按素材使用实图、双栏对照、分镜漫画或截图批注。

## 能做什么

- **设计首图。** 从读者遇到的具体问题出发，确定封面标题、字体层级和能说明问题的主画面，并安排下一张怎么兑现标题。
- **制作整组图文。** 按内容决定页数、构图和翻页顺序，可先交逐页大纲或一张首图样片，再按定稿延展整组。默认交付 1080 × 1440 的竖版 PNG，可按平台调整。
- **改稿和复盘。** 按指定范围修改，也可以根据后台的划走率、浏览张数和收藏数据提出下一轮测试方案。需要时可补写发布标题和配文。

## 怎么用

在已加载该技能的 Codex 对话中输入 `$editorial-carousel`，附上原稿、可用截图或已有样片，再说明这次想拿到什么。

> 用 $editorial-carousel 把这份 AI 做 PPT 的教程改成抖音图文。先交封面和第 2 张方案，用两版 PPT 的真实差异讲清楚为什么要先问听众是谁。

> 用 $editorial-carousel 对照这三条作品的后台截图，判断下一条先测标题、主图还是第 2 张，并给具体改稿。
