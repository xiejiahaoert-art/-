# 按内容选择版式与翻页顺序

先确定读者读完能看懂什么、选对什么或做成什么。从素材里挑最能完成这个任务的证据，例如真实对话、同一输入的两份结果、操作截图或可复制的模板。让版式把证据里的关系呈现出来。

## 看内容需要哪种关系

| 读者要做的事 | 版式 | 一组图怎么往下走 |
|---|---|---|
| 看事情怎么发生 | 连续分镜、分块漫画、对话 | 场景 → 动作 → 后果。每格发生一个能看出来的变化。用格子排列、对话气泡位置和人物动作把阅读路线交代清楚。 |
| 看出两个结果的区别 | 同屏双栏、并排截图、前后稿 | 先把同一输入或同一比较维度放在一起，再圈出关键差异，最后解释它为什么重要。控制对比的其他条件，或明确说明哪些条件一起变了。 |
| 跟着完成一个操作 | 步骤截图、局部特写、结果预览 | 给预期结果 → 按能完成的动作分图 → 展示怎么验收。把字段、按钮、报错说明贴在对应区域旁。 |
| 先做一个判断 | 案例题、对话题、答案批注 | 提供有线索的具体场景 → 下一张揭晓 → 标出判断依据。可再放一个条件相近的例子检验是否会用。 |
| 理解原因或选自己的路径 | 因果图、分岔图、批注页 | 用因果图交代哪一步引起结果变化。用分岔图把选择条件放在分支旁，并给每条路径一个明确动作。 |

同一篇可以组合这些版式。比如漫画让读者看懂为什么返工，双栏让人看到两版结果的差别，批注解释差异，最后一张给模板。遇到只有单个实用动作的素材，一张标注清楚的截图也可以完成该页任务。

## 编排页面

1. **先定第 2 张的交付。** 选一个看得见的比较结果、案例答案、操作成果或能直接使用的短句。再用它定首图的主题与悬念，让下一翻兑现首图。
2. **按发现和动作分图。** 每张写清 `读者先看到什么｜这张新增什么｜下一张接什么`。并列结果放在同一张；过程在动作、条件或结果发生变化时切页。相邻两页在重复同一说明时，考虑合并。
3. **让读者在一张图里完成当前任务。** 比较项对齐，批注贴近对象，分格有清晰起点。用约 360 px 的手机宽度检查主体、阅读顺序和关键文字。需要细读的局部可单独放大成一张。
4. **按知识和操作缺口增页。** 内容偏少时，先回看原稿是否漏了概念、状态变化、操作步骤、适用条件或验收。能独立交付一次操作的环节可以另开一页。扩页后逐页补足案例、条件或结果，让每张都交付一个可用的东西。
5. **让版式跟关系走。** 版本变化可以用一侧讲背景、另一侧排时间线。误删和取旧稿可同屏对照。跨设备操作按两台电脑分区。平台选择让条件和对应分支并排。整组可沿用同一视觉语言，各页的阅读路线由内容关系决定。

首图确定任务后，按 [封面标题、字体和主视觉](cover-design.md) 选择要放大的文字和画面。

## 示例

- **同一份大纲做两种 PPT。** 两格漫画交代「让 AI 按大纲做 PPT，结果把实操课做成概念课」→ 双栏比较新人入门和熟手实操的第一页 → 放大并批注差异 → 给「先问听众、时长和课后目标」的提示词。同一位置优先用真实输出，模拟画面标作示意。
- **用 AI 改周报。** 同屏放同一份周报的改前和改后，在具体变化旁加批注，再演示如何保留格式要求或导出交稿。
- **面试追问 Skill。** 用对话给一个候选人的回答和具体任务，让读者判断触发条件是否足够明确。下一张圈出答案缺的条件，再用一个本来不该触发的案例说明边界。

- **一份毕设讲 Git 和 GitHub。** 以 8 张为例，封面同屏给出本地和远端的差异 → 看 5 次提交的时间线 → 做第一次提交 → 并排演示找旧图和恢复误删 Word → 比较本地第 5 版与远端第 4 版 → 从推送做到换机克隆 → 按权限选托管 → 用 AI 指令和验收命令收尾。新增的操作页各有动作、命令和完成依据。篇幅按原稿的环节和用户指定页数调整。

## 研究依据

- **漫画阅读路径。** 实验和眼动研究显示，格子的空间关系会改变阅读顺序。版式有歧义时，画面与文字的位置也会影响顺序。分格可以变化，同时要让关键事件的路线容易辨认。 [Cohn，2013](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2013.00186/full) · [Kirtley 等，眼动研究](https://onlinelibrary.wiley.com/doi/full/10.1002/acp.4018)
- **先对照后解释。** 在课堂实验中，先分析差异明显的案例再听解释，有助于把学到的概念用于新案例。并排显示是手机画幅下便于比较的一种做法。 [Schwartz 与 Bransford，1998](https://aaalab.stanford.edu/assets/papers/earlier/A_time_for_telling.pdf)
- **分段与就近标注。** 自行推进的分段动画改善了学习者把所学用于新问题的表现。需要结合图和文字才能理解时，实验也发现就近整合有助于学习。 [Mayer 与 Chandler，2001](https://tecfa.unige.ch/tecfa/teaching/methodo/Mayer_Chandler01.pdf) · [Chandler 与 Sweller，1992](https://onlinelibrary.wiley.com/doi/abs/10.1111/j.2044-8279.1992.tb01017.x)
- **先判断再揭晓。** 在数字常识实验里，先作预测的参与者对答案更好奇。用具体、有线索的案例尝试这一结构，并在下一张给答案。 [Brod 与 Breitwieser，2019](https://pubmed.ncbi.nlm.nih.gov/31646002/)

这些实验测量的是阅读路径、学习表现或好奇心。用到账号上时，按 [封面与第 2 张的验证方法](cover-design.md#验证封面与第-2-张) 对齐数据口径。
